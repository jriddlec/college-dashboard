# College Dashboard 1.0

The first proper release. Your classes, deadlines, grades and study notes on
one page you host yourself, with Brightspace (D2L) or Canvas.

## New in this release

- **Setup guide.** On first launch, the app walks you through connecting your
  school, finding your class folders, phone alerts, and calendar sync.
- **Settings page.** Alerts, reminder timing, quiet hours, sync interval and theme,
  all from the browser.
- **Planner.** Assignments and calendar in one place.
- **Simpler docs.** A short README and a step-by-step
  [install guide](https://github.com/jriddlec/college-dashboard/blob/v1.0.0/docs/install.md)
  for your own computer or a home server.

## Install

You need Docker. Download **Source code (zip)** below, unzip it, and in that folder:

```bash
cp .env.example .env
mkdir -p data previews d2l-auth state
docker compose up -d --build
```

Open http://localhost:3000 and follow the setup guide. Windows and home-server
steps are in the [install guide](https://github.com/jriddlec/college-dashboard/blob/v1.0.0/docs/install.md).

## Upgrading

```bash
git pull
docker compose up -d --build
```

Canvas support is built from the official API docs and hasn't been tested
against a live school yet. Reports welcome.
